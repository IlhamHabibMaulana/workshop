# Product Requirements Document (PRD)
## Aplikasi To-Do List (Task Management System)

---

### 1. Identitas & Tujuan Aplikasi
* **Nama Aplikasi:** Aplikasi To-Do List
* **Tipe Aplikasi:** Single Page Application (SPA) Web-based Task Management
* **Deskripsi Sistem:** Aplikasi To-Do List berbasis web untuk mencatat, mengorganisasi, dan mengelola daftar tugas harian secara efisien dan intuitif. Sistem memungkinkan pengguna untuk membuat tugas baru, mengatur tenggat waktu (*deadline*), memperbarui deskripsi atau status pengerjaan (*Pending* / *Completed*), serta menghapus tugas yang sudah tidak diperlukan.
* **Capaian Utama (Main Achievement):** 
  * Terbangunnya aplikasi manajemen tugas berbasis web yang fungsional penuh.
  * Implementasi siklus hidup pengelolaan data tugas secara utuh (CRUD).
  * Manajemen perubahan status dinamis (*Pending* / *Completed*) secara instan melalui aksi cepat (*quick toggle*).
  * Validasi input formulir dan format tanggal tenggat waktu (*deadline*).
* **Batasan Scope (Out of Scope):**
  * Tidak mencakup kolaborasi atau pembagian tugas multi-pengguna (*multi-user assignment*).
  * Tidak mencakup integrasi kalender pihak ketiga (misal: Google Calendar / Outlook).
  * Tidak mencakup pengiriman notifikasi push, SMS, atau email pengingat.

### 2. Spesifikasi Fungsional Lengkap (CRUD, Filter & Metrik)

### 3. Spesifikasi Skema Data (Supabase PostgreSQL)

Sesuai spesifikasi Modul 2 SKPL, tabel database diberi nama `tasks` dengan struktur field yang identik:

#### Tabel: `public.tasks`

| Nama Kolom | Tipe Data PostgreSQL | Constraint / Aturan Validasi | Keterangan |
| :--- | :--- | :--- | :--- |
| `id` | `BIGINT` | `PRIMARY KEY GENERATED BY DEFAULT AS IDENTITY` | Identifikator unik untuk setiap entitas tugas pengguna. |
| `judul` | `VARCHAR(150)` | `NOT NULL`, `CHECK (char_length(trim(judul)) > 0)` | Judul tugas (wajib diisi, maksimal 150 karakter, tidak boleh hanya whitespace). |
| `deskripsi` | `TEXT` | `NULLABLE` | Uraian atau rincian instruksi tugas. |
| `deadline` | `DATE` | `NULLABLE` | Tanggal batas akhir penyelesaian tugas (format: YYYY-MM-DD). |
| `status` | `VARCHAR(20)` | `NOT NULL`, `DEFAULT 'Pending'`, `CHECK (status IN ('Pending', 'Completed'))` | Status pengerjaan tugas. Hanya menerima nilai `'Pending'` atau `'Completed'`. |
| `created_at` | `TIMESTAMPTZ` | `NOT NULL`, `DEFAULT timezone('utc'::text, now())` | Waktu pencatatan tugas ke dalam database (audit trail). |
